# Netflix Content Exploratory Data Analysis Project

[![Python](https://img.shields.io/badge/Python-3.13%2B-blue.svg)](https://www.python.org/)
[![Seaborn](https://img.shields.io/badge/Seaborn-Visualizations-orange.svg)](https://seaborn.pydata.org/)

This repository contains an exploratory data analysis project exploring Netflix content trends, country distributions, and movie vs. TV show ratios using Matplotlib and Seaborn[cite: 16].

---

## Dataset Notice
*Note: The dataset (`netflix1.csv`) used in this project[cite: 16] is publicly available on Kaggle.*

---

## Project Workflow & Visualizations
* **Content Type Distribution**: Comparing movie counts against TV show counts[cite: 16].
* **Country Analysis**: Visualizing the top 10 countries producing Netflix titles[cite: 16].
* **Release Trends**: Tracking yearly release trajectories from the year 2000 onwards[cite: 16].
* **Web Application**: Interactive deployment interface built with Streamlit.
